◎ Como ler este balanço

Recorte: sem esporte — o foco é poder, economia e sociedade. Cada veículo tem um posicionamento definido em sources.yaml e todas as suas matérias herdam esse valor. Não há análise matéria a matéria — o mesmo jornal aparece sempre no mesmo lugar do espectro.

É o mesmo critério do Ground.news: avalia-se o veículo, não o texto isolado. Aqui sem AllSides/MBFC, a tabela é curadoria manual.

Checagens: o selo ⚑ liga a história a uma verificação do G1 Fato ou Fake ou da Agência Lupa quando a alegação coincide. É uma checagem relacionada, não um veredito sobre a matéria.

Corpos completos (quando públicos) alimentam só a análise; na tela aparecem a description pública ou trechos curtos, sempre com link para o original.

Protótipo: — fontes · atualize rodando python app.py.
